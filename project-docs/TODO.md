## 任务列表

### 8.1 坐标转换测试 ⭐⭐⭐ (P1)

#### 任务描述
验证点标注的像素坐标与归一化坐标转换的正确性。

#### 验收标准
- [ ] 点标注创建时，pixel 和 normalized 坐标计算正确
- [ ] 图片缩放后，点标注位置保持正确
- [ ] 导出数据中坐标值符合预期
- [ ] 导入数据后点标注位置正确恢复

#### 测试用例
1. 在图片四个角创建点，验证坐标值
2. 在图片中心创建点，验证归一化坐标为 (0.5, 0.5)
3. 缩放画布后验证坐标未发生偏移
4. 导出再导入，验证坐标一致性

### 8.2 标签编辑测试 ⭐⭐⭐ (P1)

#### 任务描述
全面测试标签编辑功能，包括空值校验、唯一性校验等。

#### 验收标准
- [ ] 双击标签可进入编辑状态
- [ ] 标签编辑后失焦自动保存
- [ ] 标签不允许为空（有合理的校验逻辑）
- [ ] 标签重复时有提示或自动处理

#### 测试用例
1. 创建多个点，编辑标签
2. 尝试设置空标签
3. 尝试设置重复标签
4. 在 brush 模式下尝试编辑标签（应不可编辑）
5. 测试 focusout 时编辑器状态

### 8.3 撤销/重做完整性测试 ⭐⭐⭐ (P1)

#### 任务描述
确保所有操作都能正确撤销和重做。

#### 验收标准
- [ ] 点标注创建可以撤销和重做
- [ ] 点标注删除可以撤销和重做
- [ ] 点标注移动可以撤销和重做
- [ ] 笔刷绘制可以撤销和重做
- [ ] 笔刷擦除可以撤销和重做
- [ ] 清除所有操作可以撤销和重做
- [ ] 多次撤销后重做链完整
- [ ] 历史记录限制生效（超过 100 步自动丢弃最早记录）

#### 测试用例
1. 创建点 → 撤销 → 点消失 → 重做 → 点恢复
2. 删除点 → 撤销 → 点恢复 → 重做 → 点消失
3. 连续绘制多笔 → 逐一撤销 → 逐一重做
4. 清除所有 → 撤销 → 全部恢复
5. 执行 110 步操作 → 验证最早 10 步已不可撤销
